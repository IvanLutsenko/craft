# Space

Talk: "Crashlytics: from manual analysis to a team of subagents". A launch metaphor: crashes as failed launches, the tooling as a mission control. Fits Cosmonautics Day on April 12.

- Palette: deep navy, sand for headings, steel blue for lines, amber as the accent.
- Type: IBM Plex Sans for words, IBM Plex Mono for code.
- Signature: sand headings with slight tracking, like a mission patch.
- Decor: two star fields twinkling out of phase and a faint planet at the corner. The original also had rockets crossing the slide.

Lessons from the original:

- Body text was set in mono and read like a terminal. Mono is for code only.
- QR codes came from an online API and failed without a network. Use `scripts/qr.py`.
- One slide paired a portrait of the space program's chief designer with a QR code. A historical reference works when it is one image with a clear caption.
