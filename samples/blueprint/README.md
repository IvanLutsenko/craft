# Blueprint

Original deck: <https://ivan.nullptr.party/res/podlodka-16-crash-to-jira.html>. It is the real reference: open it and page through before writing a new theme. `theme.css` here only shows how its techniques map onto Craft roles.

Talk: "Crash to Jira", Podlodka. No holiday: a short technical deck styled as an engineering drawing.

- Palette: navy paper, pale cyan lines, amber for the one thing that matters.
- Type: Cormorant Garamond for headings, IBM Plex Mono for text and numbers.
- Signature: the title block. The slide number reads as a sheet number, the hero line is lowercase.
- Decor: a fine grid and a double frame. Nothing moves: a drawing does not move.

Lessons from the original:

- The footer carried a revision and a date in caps with letter spacing. It looked right and read badly from the back row. One quiet sheet number is enough.
- The Harold picture was duotoned to the palette. A themed picture works better when the image model draws it in the palette from the start.
- An organizer-branded copy of the deck only swapped the cover image. In Craft that is a second cover slide, not a second file.
